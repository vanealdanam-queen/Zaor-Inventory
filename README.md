# Sistema de Inventario Zaor

Un prototipo de sistema de inventario y carrito de compras desarrollado con React, creado para reemplazar el seguimiento manual mediante Excel. El proyecto fue desarrollado como parte de un proyecto escolar basado en Scrum.

## Información del Sprint

* **Sprint:** Sprint 1
* **Duración:** 31 de agosto – 2 de septiembre de 2026
* **Proyecto:** Sistema de Inventario
* **Tecnología:** React
* **Herramientas:** Jira, GitHub, React, Local Storage

## Objetivo del Sprint

Desarrollar la estructura inicial de un prototipo de sistema de inventario en React: definir su alcance y funcionalidades, crear la estructura del proyecto y establecer un mecanismo para almacenar, recuperar y mostrar los productos junto con su disponibilidad.

## Sprint Backlog

### ZAOR 1 – Definir el alcance y las funcionalidades del prototipo

**Objetivo:** Determinar las principales funcionalidades que tendrá el prototipo.

**Resultado esperado:**

* Alcance del prototipo definido.
* Principales funcionalidades identificadas.
* Requisitos iniciales documentados.

### ZAOR 2 – Crear la estructura de archivos del proyecto

**Objetivo:** Crear y organizar la estructura inicial del proyecto utilizando React.

**Resultado esperado:**

* Proyecto de React configurado.
* Carpetas y archivos organizados.
* Componentes iniciales creados.

### ZAOR 3 – Crear la estructura de datos del inventario

**Objetivo:** Definir la estructura que representará la información de cada producto.

**Resultado esperado:**

* Modelo de datos definido.
* Productos representados como objetos.
* Información como nombre, precio, cantidad y disponibilidad incluida.

### ZAOR 4 – Guardar y recuperar el inventario utilizando Local Storage

**Objetivo:** Implementar la persistencia de los datos del inventario utilizando Local Storage.

**Resultado esperado:**

* Inventario guardado en Local Storage.
* Inventario recuperado al iniciar la aplicación.
* Los datos permanecen disponibles después de recargar la página.

### ZAOR 5 – Mostrar los productos en el catálogo

**Objetivo:** Crear una interfaz para visualizar los productos registrados.

**Resultado esperado:**

* Catálogo funcional.
* Productos mostrados de manera organizada.
* Información relevante visible para el usuario.

### ZAOR 6 – Mostrar la disponibilidad de los productos

**Objetivo:** Mostrar visualmente la disponibilidad de cada producto.

**Resultado esperado:**

* Productos disponibles identificados.
* Productos agotados identificados.
* Estado de disponibilidad visible en el catálogo.

## Criterios de Aceptación del Sprint

El Sprint 1 se considerará completo cuando:

* El proyecto de React se ejecute correctamente.
* La estructura inicial del proyecto esté organizada.
* Exista una estructura de datos para representar los productos.
* El inventario pueda guardarse en Local Storage.
* El inventario pueda recuperarse desde Local Storage.
* Los productos puedan visualizarse en un catálogo.
* Se pueda identificar la disponibilidad de cada producto.
* El código fuente esté almacenado en GitHub.
* La documentación del Sprint esté disponible.

## Definición de Terminado (Definition of Done)

Una tarea se considera terminada cuando:

* El código está implementado.
* La funcionalidad ha sido probada.
* No existen errores críticos.
* El código está integrado al proyecto.
* La tarea correspondiente está actualizada en Jira.
* Los cambios están registrados en GitHub.
* La documentación correspondiente está actualizada.

## Entregable del Sprint

Al finalizar el Sprint 1, se espera contar con un prototipo inicial de inventario desarrollado en React, capaz de almacenar y recuperar productos mediante Local Storage, mostrar dichos productos en un catálogo y mostrar su disponibilidad.

## Herramientas Utilizadas

* **Jira:** Gestión del Product Backlog y Sprint Backlog.
* **React:** Desarrollo de la interfaz y lógica del prototipo.
* **GitHub:** Control de versiones y almacenamiento del código.
* **Local Storage:** Persistencia de datos local.

## Cómo iniciar el proyecto

```bash
npm install
npm run dev
```

La aplicación se ejecutará en:

`http://localhost:5173/`
